---
title: Envelope
description: Validating identity codec for ur:envelope (tag 200).
---

`envelopeCodec` is a validating identity codec. `untaggedCbor` / `fromUntaggedCbor` run `assertEnvelopeContent` and return the same `Cbor`. The UR body is untagged envelope-content. Nested wrap uses tag 200; leaves use tag 201.

`assertEnvelopeContent` is recursive. Depth 0 is the UR body. Depths 0 through 64 inclusive are accepted (65 frames). Depth 65 is `OutOfRange`. Do not use `>= 64`.

| Arm               | Rule                                                                       |
| ----------------- | -------------------------------------------------------------------------- |
| tag 201           | leaf. Content is `any`. Do not walk.                                       |
| tag 200           | wrap. Recurse on content at `depth + 1`.                                   |
| tag 40000         | known-value. Content is unsigned int. Stop.                                |
| tag 40002 / 40003 | encrypted / compressed. Content opaque. Stop.                              |
| bstr length 32    | elided digest. Stop.                                                       |
| array length ≥ 2  | node. Subject then assertion-elements (map size 1 or elided 32-byte bstr). |
| map size 1        | assertion. Recurse on key and value.                                       |
| anything else     | `WrongType`                                                                |

`["Alice", { "knows": "Bob" }]` (no tag 201) is `WrongType`.

This codec does not elide, encrypt, sort assertions by digest, or name known-values. It does not export `elide()`.
