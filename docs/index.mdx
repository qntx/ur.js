`@qntx/ur` encodes and decodes [Uniform Resources](https://github.com/BlockchainCommons/Research/blob/master/papers/bcr-2020-005-ur.md) (UR): Bytewords, fountain codes, and single- or multi-part UR strings.

It is bytes-first and wire-compatible with [bcur](https://github.com/qntx/bcur), ur-rs, and Blockchain Commons references. There is no application type registry in core.

Status: **0.1.0** transport. Interop goldens against bcur/ur-rs pass. Default decoder limit numbers may change before 1.0.
