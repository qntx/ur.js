---
title: Install
description: Add @qntx/ur with bun or npm.
---

```bash
bun add @qntx/ur
```

```bash
npm i @qntx/ur
```

Package name is `@qntx/ur`. The GitHub repository is `qntx/ur.js`.

Supported runtimes: Node 20+ and Bun. The published `dist` is ESM and does not import Node builtins; browser is not a 1.0 support claim.
