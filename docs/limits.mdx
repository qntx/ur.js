---
title: Decoder limits
description: Default DecoderLimits and poison behavior.
---

`DEFAULT_LIMITS` (frozen production Default; same integers as bcur 1.0):

| Limit                   | Default   |
| ----------------------- | --------- |
| `maxMessageLength`      | 1 048 576 |
| `maxFragmentCount`      | 2 000     |
| `maxFragmentDataLength` | 8 192     |
| `maxBufferParts`        | 4 000     |
| `maxReceivedParts`      | 8 000     |
| `maxUriLen`             | 8 192     |

Override with `new Decoder({ limits: { … } })` or `new FountainDecoder({ … })`. Exceeding a limit **poisons** the session: later `receive` and `message` throw `UrError` with code `ResourceLimit`, including `uri_len` on `Decoder`.

`maxUriLen` is compared to `String.length` (UTF-16 code units), not UTF-8 bytes.
