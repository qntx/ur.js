---
title: UR types
description: v2 UR type tokens and CBOR tags on @qntx/ur/registry.
---

L5 codecs use v2 type tokens. The first `codec.tags[0].name` is the UR type. v1 `crypto-*` tokens are a different protocol and fail `UnexpectedType`.

| UR type | Tag   | Codec       | Notes                                                              |
| ------- | ----- | ----------- | ------------------------------------------------------------------ |
| `seed`  | 40300 | `seedCodec` | Map keys 1–4. Payload 1..=64 bytes. `creation-date` is tag 1 only. |
| `psbt`  | 40310 | `psbtCodec` | Untagged bstr. Magic `70736274ff`. No input/output parse.          |

Later minors add `hdkey` (40303), `keypath` (40304), `coin-info` (40305), `sskr` (40309), and `envelope` (200). Those codecs are not in 1.2.0.

| Not decoded    | Tag |
| -------------- | --- |
| `crypto-seed`  | 300 |
| `crypto-hdkey` | 303 |
| `crypto-psbt`  | 310 |
| `crypto-sskr`  | 309 |

Seed date tag 100 (`#6.100`) is not a reader. Official digest for payload `c7098580125e2ab0981253468b2dbc52` is SHA-256 `e824467caffeaf3bbc3e0ca095e660a9bad80ddb6a919433a37161908b9a3986`.
