---
title: UR types
description: v2 UR type tokens and CBOR tags on @qntx/ur/registry.
---

L5 codecs use v2 type tokens. The first `codec.tags[0].name` is the UR type. v1 `crypto-*` tokens are a different protocol and fail `UnexpectedType`. Mixed-type decode uses host-provided `codecMap`; duplicate tokens throw `TypeError`. There is no global registry.

| UR type     | Tag   | Codec           | Notes                                                                                        |
| ----------- | ----- | --------------- | -------------------------------------------------------------------------------------------- |
| `seed`      | 40300 | `seedCodec`     | Map keys 1–4. Payload 1..=64 bytes. `creation-date` is tag 1 only.                           |
| `hdkey`     | 40303 | `hdKeyCodec`    | Untagged top-level map. Nested `origin`/`children` tag 40304; `use-info` tag 40305.          |
| `keypath`   | 40304 | `keypathCodec`  | Components array of index/range/wildcard/pair. Empty components require `sourceFingerprint`. |
| `coin-info` | 40305 | `coinInfoCodec` | `type` uint31 and `network` int. Omit 0 on write (BTC mainnet).                              |
| `sskr`      | 40309 | `sskrCodec`     | 5-byte header ‖ share-value. Domain stores N not N-1. Reserved nibble 0. No split/combine.   |
| `psbt`      | 40310 | `psbtCodec`     | Untagged bstr. Magic `70736274ff`. No input/output parse.                                    |
| `envelope`  | 200   | `envelopeCodec` | Untagged envelope-content. Identity after `assertEnvelopeContent`. Depths 0..=64. No elide.  |

`hdKeyCodec` does not check BIP44 cointype against the origin path and does not check parent-fingerprint isomorphism. Official HDKey vector 2 (`use-info` `{2: 1}` with path `44'/1'/1'/0/1`) is the lock. Nested embeddings are tagged; the `ur:hdkey` body is not.

`hdKeyDigestSource` is dCBOR `[keyData, chainCode or null, coinType, network]`. Master uses `0, 0`. Derived fills `useInfo` defaults with 0. Vector 2 uses `network = 1` even though the BCR comment says mainnet.

`envelopeCodec` does not elide, encrypt, or sort assertions by digest. Nested wrap is tag 200; the `ur:envelope` body is untagged.

| Not decoded    | Tag |
| -------------- | --- |
| `crypto-seed`  | 300 |
| `crypto-hdkey` | 303 |
| `crypto-psbt`  | 310 |
| `crypto-sskr`  | 309 |

Seed date tag 100 (`#6.100`) is not a reader. Official digest for payload `c7098580125e2ab0981253468b2dbc52` is SHA-256 `e824467caffeaf3bbc3e0ca095e660a9bad80ddb6a919433a37161908b9a3986`.
